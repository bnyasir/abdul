ABDUL SAJED CAR — CAR SHOWROOM MANAGEMENT SYSTEM
Vanilla HTML, CSS and JavaScript only. No React, TypeScript, Vite, Tailwind or build step.

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in a modern browser (Chrome, Edge, Firefox).
3. You can also use VS Code + Live Server for a local development server.

FEATURES IN THIS FRONT-END DEMO
- Responsive showroom management dashboard
- English / Arabic toggle with RTL layout
- Orders, showrooms, customers, invoices, employees, meetings, attendance, used cars, support tickets and revenue
- Add, edit, search and delete records
- CSV exports for records
- Basic order tracking by order ID
- Browser localStorage persistence

IMPORTANT LIMITATIONS
This is a standalone front-end demo. Data is stored only in the current browser and does not sync between users or devices. It does not provide real user authentication, secure server storage, cloud database, actual QR scanning/signing, or secure access control. Do not use it for sensitive production data without a backend and proper security.
